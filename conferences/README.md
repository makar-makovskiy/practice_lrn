# Конференции.РФ

Пользователь регистрируется, входит в систему и оставляет заявку: выбирает помещение, дату начала и способ оплаты. После завершения мероприятия можно оставить отзыв. Администратор видит все заявки, фильтрует их и меняет статус: «Новая» → «Мероприятие назначено» → «Завершено».

## На чём написано

- **База данных:** PostgreSQL
- **Бэкенд:** Node.js + TypeScript, фреймворк Express
- **Сессии:** express-session
- **Подключение к БД:** pg
- **Фронтенд:** HTML и CSS, страницы рендерятся на сервере, на клиенте чистый JavaScript (валидация форм, маска телефона, анимации)

Код разбит по слоям: репозитории для работы с БД (классы, наследуются от `BaseRepository`), сервисы с логикой (`AuthService`, `ApplicationService`, `Validator`) и маршруты. Пароли храню в виде хеша (scrypt), SQL-запросы параметризованные.

## Структура

```
db/        — schema.sql (таблицы + начальные данные) и ER-диаграмма
src/       — исходники сервера на TypeScript
public/    — стили и клиентский JS
design/    — макеты страниц под телефон 390x844
```

## Как запустить

Нужны Node.js 20+ и PostgreSQL.

1. Установить зависимости:
   ```
   npm install
   ```
2. Создать базу данных:
   ```
   createdb conferences
   ```
   (или `CREATE DATABASE conferences;` в pgAdmin)
3. Скопировать `.env.example` в `.env` и указать свои логин и пароль от PostgreSQL в `DATABASE_URL`.
4. Запустить:
   ```
   npm run dev
   ```
5. Открыть http://localhost:3000

Таблицы и администратор создаются автоматически при первом запуске.

## Команды

- `npm run dev` — запуск в режиме разработки
- `npm run build` и `npm start` — сборка и запуск собранной версии
- `npm run db:init` — только создать таблицы в БД
- `npm run design` — пересобрать макеты в папке `design/`
